# Study material — guides, showcases, templates

## Guides (read once, then distill)

- [Make a README](https://www.makeareadme.com/) — canonical guide: which
  sections deserve to exist per project type, editable template.
- [The Art of README](https://github.com/hacktivistto/The-Art-of-README) —
  structure with purpose (what / why / how / contributing).
- [thoughtbot: How To Write a Great README](https://thoughtbot.com/blog/how-to-write-a-great-readme)
  — the README as front door; 10-minute read.
- [README-Driven Development](https://tom.preston-werner.com/2010/08/23/readme-driven-development.html)
  (Tom Preston-Werner) — write the README before the code.
- [Elegant READMEs](https://www.yegor256.com/2019/04/23/elegant-readme.html)
  (Yegor) — the minimalist counterpoint; the philosophical basis of level LOW.
- [ARCHITECTURE.md](https://matklad.github.io/2021/02/06/ARCHITECTURE.md.html)
  (matklad) — where the "how it works inside" belongs instead of the README.

## Showcase READMEs — steal these moves

Master list: [awesome-readme](https://github.com/matiassingers/awesome-readme).

| Project | What to steal |
|---|---|
| [doomemacs/doomemacs](https://github.com/doomemacs/doomemacs#readme) | centered title, badge row, UI screenshot, personality and humor |
| [GyulyVGC/sniffnet](https://github.com/GyulyVGC/sniffnet#readme) | custom banner, badge tokens, install table, footer with socials |
| [CCOSTAN/Home-AssistantConfig](https://github.com/CCOSTAN/Home-AssistantConfig#readme) | the dotfiles formula: banner + badges + nav |
| [sourcerer-io/sourcerer-app](https://github.com/sourcerer-io/sourcerer-app) | animated GIF as the hero |
| [yvann-ba/ft_transcendence](https://github.com/yvann-ba/ft_transcendence#readme) | minimal banner + GIF gallery in a table; the "quiet showcase" |

## Templates and specs (for section checklists)

- [Standard Readme](https://github.com/RichardLitt/standard-readme) — spec
  with fixed sections (Background / Install / Usage / Related).
- [Zalando README Template](https://github.com/zalando/zalando-howto-open-source/blob/master/READMEtemplate.md)
  — corporate sober.
- [READMINE](https://github.com/mhucka/readmine) — maximalist
  self-describing template.
- [Amazing GitHub Template](https://github.com/dec0dOS/amazing-github-template)
  — pack: README + CONTRIBUTING + LICENSE + issue templates.
